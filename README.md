# Shivani Shrivastava — Personal Profile Website

A simple, responsive personal profile website built using a **single HTML file** with embedded CSS and JavaScript.

## 🌐 About

This website serves as a personal portfolio/profile for **Shivani Shrivastava**, a 2nd-year Bachelor of Engineering student specializing in Information Technology at Thakur College of Engineering and Technology (TCET).

It showcases:

- Personal introduction
- Education
- Technical skills
- Projects
- Technical activities
- Club involvement
- Contact information

## ✨ Features

- Single-file website
- Responsive design for desktop and mobile
- Dark modern UI
- Smooth scrolling navigation
- Interactive navigation highlighting
- Project cards
- Skills section
- Education timeline
- Contact section
- No external libraries or frameworks required

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
profile-website/
│
├── index.html
└── README.md
````

The entire website is contained inside `index.html`.

## 🚀 How to Run

### Method 1 — Open Locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your default browser.

### Method 2 — Using VS Code

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server** if the Live Server extension is installed.
